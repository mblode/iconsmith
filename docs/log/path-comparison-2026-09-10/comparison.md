# Iconsmith generation path comparison

The strongest observed approaches were AI authoring with self-inspection and AI authoring with critic-guided repairs. Neither achieved ten usable icons. The default now prioritizes competing AI candidates, independent visual review and repairs over cost or speed; this is a development workflow, not a qualified 10/10 pipeline.

The API builder returned eight invalid programs, including invented DSL vocabulary. The tool loop delivered seven valid drafts, then timed out on server-off. Its unresolved cost receipt stopped the last two requests in each API arm; these were unstarted, not reviewed failures.

## Remaining paths

- Contained native AI author plus reviewers: one construction attempted, no output delivered; Docker cleanup and accounting remained unproven. Nine requests unstarted. Drawing quality is unranked because the runtime failed before review.
- Mark and glyph recipes: all twenty requests refused unsupported compound names. Useful for their fixed vocabulary; no coverage of this cohort.
- Source reconstruction: reproduces an existing admitted answer. Ineligible as evidence for generating missing icons.
- Source-plus-badge splicing and corpus analog composition: require suitable admitted sources absent from the public starter packet. Not freshly evaluated with a full corpus; no claim of universal inferiority.
- Direct SVG/Quiver: historical four-bell experiment delivered SVG but lacked constrained program replay and independent qualified scores. Current credentials unavailable; unranked against this cohort.
- Raster generation and raster-to-layout: historical image proposals existed, but the autonomous editable SVG adapter was incomplete. No comparable end-to-end output; unranked.
- Manual drawing: the CLI compiles a supplied program; it is not an independent author. No human drawing trial was conducted. This comparison does not establish that AI beats skilled human drawing.
- Mixtures, candidate selection and repair are workflow strategies around authors, not additional geometry engines.

## Default and acceptance

The public agent brief now calls for two independent authors, anonymous independent review by two fresh reviewers, free recognition before target disclosure, light/dark and native/enlarged inspection, and preserved localized repairs. Both reviewers must score at least 9, approve unchanged and identify no critical defect or semantic uncertainty. Up to three repair rounds are allowed; unresolved results are rejected. Exact replay and structural checks remain necessary but cannot approve craft.

The CLI now defaults to AI with no cheap fallback. It explicitly reports drafts as structural-only and craftApproved=false. The multi-agent review workflow is executed by the user's coding agent through the included brief; the CLI itself does not automatically enforce those visual reviews. Explicit experimental route flags remain available. No sealed qualification gate was promoted.

## Evidence limits and cost

These are exposed development concepts and uncalibrated AI reviewers, not sealed qualification or human preference. Authors used the same session model in separate contexts; the API used Opus 5. Repair and API cohorts had fresh reviewer panels. API tools received style references while the existing JavaScript builder used its spec/policy interface. Deadline bounds also differ. Results rank these observed configurations, not intrinsic model capability. The starter references are not the complete Blode family; 16px was a downsample, not a separately authored optical master.

Recorded API cost: $1.591246, plus a $10 reservation whose final cost is unknown after timeout. Native subscription cost is unknown, with one call's containment/accounting unresolved. Historical liabilities remain unchanged. No further paid dispatch was made after uncertainty. Docker restart requires approval because it can interrupt unrelated containers; an exact-owned-container removal also timed out.

All 2,377 engine tests, typecheck, build, lint and diff checks passed after the runtime diagnostic fix. Public packet smoke also passed. These validate implementation and onboarding, not visual qualification.

The gallery retains rejected drafts as well as accepted candidates. Raw blind review and semantic assessments are retained alongside this report; aggregate results are in ranking.json.
