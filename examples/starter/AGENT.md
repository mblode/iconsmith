# Create an icon

Follow the canonical workflow in [the Iconsmith skill](../../packages/iconsmith/SKILL.md).
Create the user's requested concept, or `square-check` if no concept was supplied.

From this source checkout, build with `npm run build:local`, then use
`node packages/iconsmith/dist-agent/cli.js` wherever the skill says `iconsmith`.
The workflow, review rubric and delivery requirements live only in that skill.
